Prozessautomatisierung mit Camunda 7

Für das fiktive Verpackungsunternehmen PackToTheRoots haben wir einen Auftrags- und einen Reklamationsprozess in BPMN modelliert und mit Camunda 7 automatisiert. Im Auftragsprozess wird der Kampagnenauftrag eines Handelskunden abgewickelt, im Reklamationsprozess werden Kundenreklamationen bearbeitet.

Mein Beitrag

  • E-Mail-Benachrichtigungen über zwei Node.js-Worker angebunden (Camunda External Tasks, REST-API, SMTP)
  • Automatisierung der Transportbuchung mit UiPath (RPA) konzipiert
  • Formulare vereinheitlicht und alle Prozessschritte dokumentiert, inklusive Entwicklerdokumentation und Video-Tutorials
  • Camunda 7
  • BPMN 2.0
  • Node.js
  • REST-API
  • UiPath

Gym-Tracker: Webanwendung für Trainingspläne

Eine Webanwendung, mit der Nutzer Workouts planen, Übungen suchen und ihr Training mit Gewicht, Sätzen und Wiederholungen erfassen. So wird der Trainingsfortschritt über die Zeit sichtbar.

Mein Beitrag

  • Übungssuche über eine externe Übungs-API im Backend und Frontend umgesetzt
  • Login mit Auth0 eingebaut, sodass jeder Nutzer nur seine eigenen Workouts sieht (JWT)
  • Unit-Tests für die Kernfunktionen rund um Workouts und Übungen geschrieben
  • Frontend an die REST-API angebunden und Deployment mit Docker auf Render vorbereitet
  • Java
  • Spring Boot
  • PostgreSQL
  • Vue 3
  • TypeScript
  • Auth0
  • Docker
  • GitHub Actions
